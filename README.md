# LOCO Store — стильный сайт магазина аксессуаров ✨

Адаптивная одностраничная страница, демонстрирующая новую коллекцию аксессуаров с упором на удобство
для посетителей и фирменный визуальный язык.

## 🚀 Ключевая функциональность

- Промо-блок с призывом к действию и предложением, подчёркивающим ценность новой коллекции.
- Карточка товара с интерактивным выбором цвета и акцентом на цену и количество.
- Секция с подборками образов и быстрая навигация к другим товарам.
- Блок социальных сетей с иконками бренда для расширения онлайн-присутствия.
- Адаптивный дизайн с десятком контрольных ширин для корректного отображения от десктопа до
  мобильных устройств.
- Стилизованные элементы управления и плавные состояния кнопок, усиливающие премиальное впечатление.

## 🛠️ Технологический стек

- **Разметка и доступность:** HTML5, семантические теги, `time` и `a` с правильными атрибутами.
- **Оформление и сетка:** CSS3, Flexbox, адаптивная типографика, линейные градиенты, методология
  БЭМ.
- **Ресурсы и интерфейс:** Собственные веб-шрифты (Montserrat), оптимизированные SVG-иконки и
  изображения.
- **Инструменты и качество:** Node.js, сценарии NPM, Stylelint, Prettier.

> Ключевые навыки: HTML5 · CSS3 · Flexbox · адаптивная верстка · БЭМ · Stylelint · Prettier

## 🧾 Установка и запуск

1. Склонируйте проект:

   ```bash
   git clone https://github.com/IrinaRyazanskaya/loco-store.git
   cd loco-store
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Проверьте код линтером:

   ```bash
   npm run lint
   ```

4. Откройте `index.html` напрямую в браузере или поднимите локальный сервер:

   ```bash
   npm run serve
   ```

## 📁 Структура проекта

```text
loco-store/
├── fonts/              # Веб-шрифты Montserrat в форматах woff/woff2
├── images/             # Оптимизированные изображения и SVG-иконки
├── fonts.css           # Подключение собственных шрифтов
├── index.html          # Семантическая HTML-разметка страницы
├── style.css           # Основные стили, адаптив и состояния элементов
├── package.json        # Сценарии форматирования и проверки качества
├── package-lock.json
└── README.md
```

`node_modules/` создаётся автоматически после `npm install`.

## 💡 Что реализовано / изучено

- Отработка адаптивной верстки с множеством контрольных ширин под реальные устройства.
- Построение дизайн-системы на основе методологии БЭМ и единых токенов отступов и цветов.
- Настройка Stylelint и Prettier для единообразного кода в командной работе.
- Проработка пользовательских сценариев: выбор цвета, добавление в корзину, переход к дополнительным
  предложениям.

## 🧠 Решённые задачи и технические сложности

- **Бесшовная адаптация**: переработаны сетки и типографика, чтобы блоки промо и карточки товара
  читались одинаково хорошо на ширинах от 320 до 1400+ px.
- **Собственные элементы управления**: реализованы переключатели с полностью стилизованными
  состояниями и доступностью через скрытые элементы.
- **Брендовая айдентика**: интегрированы фирменные шрифты и градиенты без потери производительности
  за счёт woff2-формата и оптимизации ресурсов.
- **Поддерживаемость кода**: структура по методологии БЭМ и линтеры помогают быстро масштабировать
  страницу новыми секциями без регрессий.
